# 翻譯機器人改善分析

> 從 LINE 聊天紀錄（A/C/D 房）抽取，2026-04-26 用 NotebookLM 跑出來的結論。
> 用途：餵進 [linebot/Code.gs](../linebot/Code.gs) 的 glossary 跟 prompt。

## 工作場合脈絡（給 prompt 用）

- **行業**：特種服務（應召工作室）
- **空間結構**：套房分 A 房、C 房、D 房等，員工在房內接客
- **角色**：
  - **老闆/派單員**（中文使用者）：派客、開大門、報價、結帳。指令簡潔，員工有需求時轉溫和安撫
  - **員工**（泰籍女）：在房接客、回報 in/out、生理狀況、收錢。對老闆極度禮貌，常用 ค่ะ + 🙏 + 愛心貼圖
  - **客人**：不在群組
  - **翻譯機**：群組裡的 bot，雙向中泰即時翻譯
- **常見主題**：客人預約／價格／服務內容、門禁開大門、員工生理狀況（吃飯、月經、受傷）、突發狀況（客人醉、未成年、偷錢）、對帳
- **語氣**：員工對老闆要保留禮貌（ค่ะ→「老闆」「呢」「嗎」），老闆對員工要保留簡潔指令感

## 易誤譯模式（給 prompt 用，這些是 AI 很容易翻錯的）

### 代詞陷阱
- **เค้า** 在這個群組脈絡通常指「客人」，不是「我」也不是「他/她」泛指
  - 例：`เจ้านายเค้าโทตามกลับด่วน` → 「**他（客人）**的老闆催他回去」（不是「我老闆」）
  - 例：`พอดีแบตเค้าหมด` → 「剛好**他（客人）**的電池沒電」（不是「我的電池」）

### 打錯字／聽錯
- **วัด**（寺廟）常常是 **บอส**（老闆）的打錯字
  - 例：`วัดค่ะลูกค้าจะขอเพิ่มไหมล่ะ` → 「老闆，客人要加鐘嗎？」（不是「寺廟」）

### 自稱／暱稱
- **นก**（Nok）多半是員工的自稱／暱稱，不是「鳥」
  - 例：`นกก็ทำงานไม่ได้` → 「我（Nok）也沒辦法接客了」（不是「鳥兒也無法工作」）

### 感嘆詞
- **ตาย**（死了）= 「完蛋了／天啊」的感嘆，不是真的死亡

### 委婉用語（行業隱語）
- **น้องสาว** 字面是「妹妹」，行業裡指「私密處／陰道」
- **มอบความรู้สึก / มอบครั้งแรก** 在客人語境下是「把第一次給她」，不是「給感覺」
- **加點** vs **加鐘**：餐廳是加點，這行業是加鐘（延長時間）

### 動作回報 vs 命令
- **Out** 是員工回報「客人離開了」，不是叫某人「出去」
- **In** 是員工回報「客人到了」，不是「進入」

## 翻錯案例（教 AI 不要這樣翻）

| 原文 | 舊翻譯機（爛） | 應該翻 |
|---|---|---|
| พี่ชายช่วยชื้อยาทาแก้เจ็บช่องคลอดให้กับน้องสาวของฉันหน่อย | 哥哥幫我妹妹買治療陰道疼痛的藥膏 | 老闆，請幫我買治療私密處疼痛的藥膏 |
| วัดค่ะลูกค้าจะขอเพิ่มไหมล่ะ | 寺廟，客人要加點什麼嗎？ | 老闆，客人想加鐘嗎？ |
| นกก็ทำงานไม่ได้อ่ะมันเจ็บท้องมากเป็นประจำเดือน | 鳥兒也無法工作，因為牠肚子很痛，是月經剛來 | 我也沒辦法接客了，月經剛來肚子很痛 |
| ตาย ฉันท / เค้าบอกเค้าชอบอยากจะมอบความรู้สึกให้ฉัน | 死了，我 / 他說他喜歡想要給我感覺 | 完蛋了 / 他說他很喜歡我，想把第一次交給我 |
| เจ้านายเค้าโทตามกลับด่วน | 老闆急忙打電話叫我回去 | 他（客人）的老闆急忙打電話叫他回去 |
| Out | 出去 | 客人離開了／服務結束 |
| ไม่มีคอน (No Con) | 沒有控制／沒有缺點 | 無套 |
