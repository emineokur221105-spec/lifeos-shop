# LifeOS-Shop 統一版

Raymond 的門店工作管理系統（多租戶版）。

## 特色

- **多租戶架構**：一個系統服務多個門店，每個租戶獨立 Firebase
- **前端管理**：租戶清單、參數設定全都在前端管理，不用改程式碼
- **Firebase v11 modular**：統一用最新 SDK
- **PWA**：可裝成 App、離線可用

## 入口

- 一般使用者：`https://<pages-url>/?t=<租戶代號>`
- 管理者後台：`https://<pages-url>/?admin=0308`
